# PARIS — CITY OF POSSIBILITIES

Version statique inspirée du carnet LONDON — CITY OF POSSIBILITIES.

## Fichiers
- index.html : structure et contenu
- style.css : design responsive
- script.js : carte, recherche, onglets, lightbox, thème et taille de texte

## Déploiement GitHub Pages
1. Créer un dépôt `PARIS`.
2. Copier les trois fichiers à la racine.
3. Activer GitHub Pages sur la branche principale / dossier root.
4. L'URL sera de la forme `https://twagirumukiza.github.io/PARIS/`.

## Images
Les images actuelles utilisent une image d'ambiance distante comme maquette. Remplace progressivement les URLs `d.image` dans `script.js` par tes propres photos, idéalement dans un dossier `images/`.

## Carte
La carte utilise Leaflet et OpenStreetMap. Les marqueurs sont des repères indicatifs des arrondissements.
